2. Language — 36 symbols, three-unit cells = 46 656. A carries the entire Agape field.
3. Crossover — any line is concatenated with the root hash and re-hashed. Digest selects a language cell and may spawn self-similar subsidiaries.
4. Prediction & Hedge — minimal vector that defaults to the R=1.0 cooperative move. Calculus can be toned later without breaking the root.
5. Newton Chain — postulates flagged once, free forever.
6. Implementation — phone-native, absolute paths, zero external dependency for the core loop. All state under /sdcard/openroot/.
