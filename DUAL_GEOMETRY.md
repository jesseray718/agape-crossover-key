# DUAL GEOMETRY — Two Candidate Structures for Intelligent Data Flow

## Hierarchical raising rule (applies to both geometries)
Six distinct core atomic functions, each performing one specific task, act together as a single cooperative team.
That team of six can itself become one function at the next scale.
Six such teams form a team of 36, and the same rule continues (6 → 36 → …) toward the full address space.
Coordination cost remains near zero at every scale (R ≈ 1.0).
This hierarchical raising is the preferred path that carries natural language from the terminal into the first cryptographic hash, so data arrives already structured.

## Geometry A — Classic Isotropic Vector Matrix
- One center + 12 equally spaced points.
- Each point connected to its geometric neighbors.
- Shared edges and faces; balanced in every direction.
- Supports frequency-raising by self-similar subdivision when members reach critical length.
- Clean spatial isotropy.

## Geometry B — Fully-Connected 12-Hub Wheel (+ optional IVM layer)
- Each of the 12 permaculture principles is a dense hub built from hierarchical six-function teams (scaling toward high order).
- Every hub is directly linked to all 11 others → complete graph K₁₂.
- A data packet may circulate among the hubs, accumulate confidence or score, and return only when a threshold is met.
- These 12 dense hubs can themselves be placed at the vertices of an isotropic vector matrix, adding a second geometric layer.
- Result: relational completeness (every principle talks to every other) + spatial isotropy + hierarchical intelligence inside each hub.

## Experimental status
Both geometries are hypotheses.
Neither has yet been verified by continuous joule accounting or by a live multi-hub test.
The hierarchical six-function raising rule is the common substrate and is the first element to instrument with real joule measurements and Merkle hashes.

## Necessary condition for zero-overhead cooperation
All cooperating nodes must be practicing Agape: each node serves the others selflessly.
Only under that condition does the hierarchical six-function raising and both geometries achieve coordination cost near zero (R ≈ 1.0).
Any node that extracts rather than serves re-introduces overhead and breaks the scaling rule.
